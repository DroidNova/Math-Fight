# Project rules

- Inspect existing code before editing.
- Implement only the explicitly requested milestone.
- Preserve working behavior and user changes.
- Avoid unrelated refactors, boilerplate, and dependencies.
- Do not assume branch names, commit SHAs, remotes, or ancestry.
- Build when appropriate.
- Do not add or run automated tests unless explicitly requested.
- Report changed files, build results, manual verification steps, and anything unverified.
- Do not advance to the next milestone without the user requesting it.
